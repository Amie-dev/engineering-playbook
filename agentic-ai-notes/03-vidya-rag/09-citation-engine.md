# File 09: Source Citation Engine (`src/generation/citation-engine.js`)

## Overview
The **Source Citation Engine** parses inline citation markers (`[Doc 1]`, `[Doc 2]`) generated by the LLM, mapping them back to original document filenames, subject categories, and passage snippets to render verified bibliographic references.

---

## 1. Citation Processing Flow

```mermaid

    RawLLM[Raw LLM Answer with [Doc 1] tags] --> RegexParser[Regex Citation Parser]
    RegexParser --> ExtractedTags["Extracted Citations: ['Doc 1', 'Doc 2']"]
    ExtractedTags --> MapLookup["Map Tags to Passage Metadata (filename, subject)"]
    MapLookup --> FinalPayload["Formatted Response Payload with Citations Array"]
```

## 2. Citation Engine Implementation (`src/generation/citation-engine.js`)

```javascript
export function processAnswerWithCitations(rawAnswerText, rerankedPassages) {
    // 1. Regex to find all [Doc N] references
    const citationRegex = /\[Doc\s+(\d+)\]/g;
    const matches = [...rawAnswerText.matchAll(citationRegex)];
    
    const citedIndices = new Set(matches.map(m => parseInt(m[1], 10) - 1));
    const citations = [];

    // 2. Map cited indices back to document metadata
    citedIndices.forEach(idx => {
        if (idx >= 0 && idx < rerankedPassages.length) {
            const passage = rerankedPassages[idx];
            citations.push({
                citationTag: `[Doc ${idx + 1}]`,
                filename: passage.filename,
                subject: passage.subject,
                snippet: passage.text.substring(0, 150) + "..."
            });
        }
    });

    return {
        answer: rawAnswerText,
        citations,
        hasCitations: citations.length > 0
    };
}
```
